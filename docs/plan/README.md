# Plans

Each plan lives in `<version>-<slug>/spec.md` and maps to `plan/<slug>`.
Separate proposed behavior from accepted and implemented behavior.
Use the [specification template](../templates/spec.md).

The initial platform and band-session direction is recorded in the
[base architecture](../feature/0.0.0.0-base/architecture.md). Future features should
receive their own numbered plans/specifications when that work begins.
