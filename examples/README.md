# Original Examples

These short studies and lyrics were created for this repository's base feature.
They are demonstration content, not the band's final repertoire.

- `evening-rehearsal.chordpro`: chart with verses, choruses, and a bridge.
- `evening-rehearsal.tab`: guitar arpeggios attached to the same song.
- `c-major-study.musicxml`: eight-bar notation fixture.
- `sunday-waltz.chordpro`: a second chart in 3/4.

Import through the library, or attach a source file to an existing song.
